# Security policy

## Supported versions

Security fixes are intended for the latest released version. Development builds may change at any time.

## Reporting a vulnerability

Please report suspected security issues privately to the repository maintainers before public disclosure. If this repository is hosted on GitHub, use **Security → Report a vulnerability** to create a private security advisory. Include the affected version, steps to reproduce, and impact. Do not include real NextDNS credentials, profile data, or sensitive request URLs in reports.

The project has no backend and should not transmit extension data to a project-controlled server. Reports about unexpected network behavior should include a sanitized reproduction where possible.
